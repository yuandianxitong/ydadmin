## 技术栈

- **UniApp** — 跨端应用框架
- **Vue 3** — Composition API
- **Wot Design Uni** — 移动端 UI 组件库
- **TypeScript** — 类型安全
- **pnpm** — 包管理器

## 项目结构

```
uniapp/
├── src/
│   ├── pages/          # 页面
│   ├── components/     # 组件
│   └── utils/          # 工具函数
├── vite.config.ts
└── package.json
```
