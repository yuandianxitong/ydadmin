## 技术栈

- **Vue 3** — 渐进式 JavaScript 框架
- **TypeScript** — 类型安全
- **Element Plus** — UI 组件库
- **Vite** — 构建工具
- **Pinia** — 状态管理
- **UnoCSS** — 原子化 CSS 引擎

## 项目结构

```
admin/
├── src/
│   ├── pages/          # 页面组件
│   ├── router/         # 路由配置
│   ├── store/modules/  # Pinia Store
│   ├── utils/          # 工具函数
│   └── components/     # 公共组件
├── vite.config.ts
```
