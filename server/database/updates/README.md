# 数据库升级指南

本目录存放每个版本的增量数据库升级脚本，供已部署实例从旧版本升级到新版本使用。

## 升级流程

1. **备份数据库** — 执行任何升级操作前，务必先备份当前数据库
2. **确认当前版本** — 查看 `server/config/version.php` 中的版本号
3. **确定升级范围** — 对照 `CHANGELOG.md`，找到当前版本到目标版本之间的所有版本
4. **按顺序执行** — 从当前版本的下一个版本开始，依次执行每个版本目录中的 `update.sql`
5. **更新版本文件** — 将 `server/config/version.php` 中的版本号更新为目标版本
6. **清除缓存** — 执行 `php think clear` 清除应用缓存

## 目录结构

```
updates/
├── README.md           # 本文件
└── vX.Y.Z/
    ├── update.sql      # 增量 SQL（ALTER TABLE、INSERT/UPDATE 等）
    └── README.md       # 本版本升级说明
```

## 注意事项

- 每个版本目录名与 `CHANGELOG.md` 中的版本号对应
- 没有数据库变更的版本不会有对应目录
- 跨多个版本升级时，必须按版本号顺序依次执行，不可跳过
- 新安装用户无需执行升级脚本，安装程序已包含最新完整数据
