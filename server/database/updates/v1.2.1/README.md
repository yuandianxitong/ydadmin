# v1.2.1 升级说明

## 升级内容

修复权限系统数据问题：

1. **修正菜单权限命名** — type=2 菜单的 `permission` 字段添加 `.list` 后缀，与权限表命名规则一致
2. **新增缺失的按钮菜单** — 补充 type=3 按钮权限（状态切换、编辑、删除、清空等）
3. **超级管理员角色授权** — 为超级管理员角色分配新增的按钮权限

## 升级步骤

1. 备份数据库
2. 执行 `update.sql`
3. 运行 `php think clear` 清除缓存
4. 将 `server/config/version.php` 中的版本号更新为 `1.2.1`
