# 元点Admin 安装程序说明

## 📁 目录结构
```
public/install/
├── index.php              # 安装入口文件和控制器
├── install.class.php      # 核心安装逻辑类
├── css/
│   └── install.css        # 安装程序样式文件
├── js/
│   └── install.js         # JavaScript功能文件
├── images/                # 图片资源目录
├── data/
│   ├── schema.sql         # 安装用数据库结构文件
│   ├── init.sql           # 初始化数据（必选导入）
│   └── demo.sql           # 演示数据（可选导入）
└── steps/                 # 安装步骤页面
    ├── license.php        # 许可协议页面
    ├── environment.php    # 环境检测页面
    ├── config.php         # 参数设置页面
    ├── install.php        # 安装过程页面
    └── complete.php       # 安装完成页面
```

## 🛠 主要修复和改进

### 1. 许可协议修复
- ✅ **修复**：未同意协议不允许进入下一步
- ✅ **改进**：使用页面内提示（toast/弹窗），不使用浏览器 alert/confirm

### 2. 环境检测修复
- ✅ **修复**：目录权限检测路径修正为`/runtime`和`/config`（与/public同级）
- ✅ **修复**：即使环境检测不通过也允许继续安装
- ✅ **改进**：添加详细的修复建议和系统信息

### 3. 界面和交互改进
- ✅ **UI框架**：使用Tailwind CSS + DaisyUI组件库
- ✅ **响应式**：完美适配移动设备和桌面端
- ✅ **用户体验**：添加加载动画、进度提示、错误处理
- ✅ **可访问性**：支持键盘导航和屏幕阅读器

### 4. 功能增强
- ✅ **数据库**：支持自动创建数据库
- ✅ **配置**：自动更新.env文件中的数据库参数
- ✅ **表前缀**：支持安装时设置数据表前缀
- ✅ **初始化数据**：安装时默认导入（字典、模板、治理规则等）
- ✅ **演示数据**：可选导入，用于快速体验业务流程
- ✅ **日志**：详细的安装日志记录

## 🚀 安装步骤

### 第1步：许可协议
- 显示软件使用协议
- 可选择同意或继续安装（即使不同意）
- 美观的协议展示界面

### 第2步：环境检测
- 检查PHP版本和扩展
- 检查目录权限（正确检测/runtime、/config目录）
- 显示修复建议
- 允许在环境不完全满足时继续安装

### 第3步：参数设置
- **数据库配置**：主机、端口、数据库名、用户名、密码
- **管理员配置**：用户名、昵称、邮箱、密码（含强度检测）
- **站点配置**：站点名称、域名
- **实时验证**：表单输入验证和数据库连接测试

### 第4步：安装过程
- 实时进度显示
- 详细步骤跟踪
- 安装日志输出
- 错误处理和重试机制

### 第5步：安装完成
- 显示安装结果
- 管理员信息确认
- 安全提示和建议
- 自动删除安装程序选项

## 🔧 配置说明

### .env文件更新
安装程序会自动更新以下配置：
```env
DB_TYPE = mysql
DB_HOST = 127.0.0.1
DB_NAME = your_database
DB_USER = your_username
DB_PASS = your_password
DB_PORT = 3306
DB_CHARSET = utf8mb4
DB_PREFIX =
APP_KEY = auto_generated_key
ADMIN_FRONTEND_URL = /admin
```

### 数据库文件
安装程序使用项目根目录下的数据库文件：
- `data/schema.sql` - 数据表结构
- `data/init.sql` - 初始化数据（安装必选导入）

## 🛡 安全建议

### 安装后必做
1. **删除安装目录**：完成安装后立即删除`public/install`目录
2. **修改密码**：登录后台后立即修改管理员密码
3. **检查权限**：确保敏感文件权限设置正确
4. **关闭调试**：生产环境关闭调试模式

### 服务器配置
1. **目录权限**：确保runtime和config目录可写（755权限）
2. **隐藏文件**：.env文件不应对外访问
3. **URL重写**：配置伪静态规则
4. **HTTPS**：生产环境启用SSL证书

## 🐛 故障排除

### 常见问题
1. **数据库连接失败**
    - 检查数据库服务状态
    - 验证连接参数
    - 确认用户权限

2. **文件权限错误**
    - 使用`chmod 755`设置目录权限
    - 检查Web服务器用户权限

3. **环境检测失败**
    - 安装所需PHP扩展
    - 升级PHP版本到8.0+

4. **安装中断**
    - 检查网络连接
    - 查看浏览器控制台错误
    - 检查服务器错误日志

### 重新安装
如需重新安装：
1. 删除`config/install.lock`文件
2. 清空数据库表
3. 重新访问安装程序

## 🎉 安装完成后
恭喜！元点Admin已成功安装。建议：
1. 删除 `public/install` 目录
2. 登录管理后台修改密码
3. 根据业务完善系统配置
